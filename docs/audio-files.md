# 音声ファイルの読込

「再生・調整」で「広帯域」→「音声ファイル」→「音声ファイルを選択」を押します。WAVに加え、MP3・FLAC・M4A/AAC・Ogg Vorbis・Opusなどを音源に使えます。読み込んだ後は停止状態なので、「再生」で開始してください。

ステレオ音源は「L採用」「R採用」「(L+R)/2」でモノラル化し、その音源へ左右それぞれの補正を適用します。シーク、ループ、ループ端5 msクロスフェード、FIR／位相・振幅の切替は従来と同じです。入力の音量を自動正規化しません。読み込めないファイルを選んだ場合は、停止したまま理由を表示し、直前の音源設定を保持します。

## 対応範囲

WAVはPCM16/24/32・IEEE float32をアプリで読み込みます。WAV以外はAndroid標準のMediaExtractorとMediaCodecを利用するため、コンテナ・コーデック・ビット深度によって端末間の差があります。[Androidの対応形式](https://developer.android.com/media/platform/supported-formats)を基に、利用できる音声トラックを判定します。対応しない形式、暗号化された音声、3ch以上、途中でPCM形式が変わるファイルはエラーを表示します。

入力は1 GiB以下、モノラルまたはステレオ、8〜192 kHz、2時間以下です。WAV以外は展開したPCMにも1 GiBの上限があり、圧縮前のサイズが小さくても上限を超えることがあります。読み込み時に48 kHzの一時PCMへ変換するため、長い音源には時間とキャッシュ領域の空き容量が必要です。

24-bit FLACを含むデコード精度は端末によって異なります。古いAndroidのFLAC読込はPCM16になる場合があります。アプリがfloat出力を要求できるFLACデコーダーではfloatを使いますが、全端末で24-bit相当の精度を保証するものではありません。WAVのPCM24/32・float32読込は従来の処理を維持しています。

設定JSONは従来の`WAV`と`wavUri`という識別子を使うため、既存設定も読み込めます。選択したファイルのURIと読込権限を保存し、アプリ起動時に再変換します。ファイルの移動や権限取消で参照できなくなった場合は、選び直してください。

## 検証方法

外部の楽曲を使わず、左440 Hz・振幅0.2、右880 Hz・振幅0.1の1秒音源を生成しています。`python tools/generate_audio_fixtures.py`で、PATH上のFFmpegを使ってテスト用WAV・MP3・FLAC・M4A・AAC・Ogg Vorbis・Opusを再生成できます。24-bit FLAC用のfloat WAVと、拒否確認用の6ch FLACも含みます。

Androidテストは無音エミュレーターで実行します。7形式の実デコード、48 kHzへの変換、左右選択・平均化、振幅とチャンネル分離、24-bit FLACの振幅、破損・多チャンネルの拒否、取消時の一時ファイル解放を検証します。アプリ側では保存設定からの再読込、モノラル選択変更、読込失敗時の旧設定保持、連続選択、MP3の通常再生・シーク・ループと、再生中の補正切替を確認します。結果とAPKハッシュは[検証記録](validation.md)に記載します。
