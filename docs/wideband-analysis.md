# 300〜3,400 Hzの保存応答によるFIR予測（2026-11-07）

準備確認後の広帯域診断1件から、集約・反復1→2・反復2→1の3候補を生成しました。交差予測の全帯域片側比は4.36〜4.42 dB、無補正両側比は7.65〜7.72 dBです。一方、周波数ごとの増音が残っています。実機の低減量や広帯域での実用性を確認した結果ではありません。

## 対象と元判定

## 主対象の全帯域とサブバンド予測

以下は「片側比 / 無補正両側比」のdB値です。有限長FIRと共通遅延を含む応答に、要求帯域の各ビンへ等エネルギーを与えています。線形電力を足してからdBへ変換しており、周波数別dBの平均ではありません。低SNRや設計対象外のビンを全帯域の評価から除外していません。

|---|---|---|---|
| 集約・1 | 3.36 / 6.65 | 5.34 / 9.08 | 142 |
| 集約・2 | 3.39 / 6.69 | 5.39 / 9.15 | 148 |
| 反復1→2・2 | 4.42 / 7.72 | 5.34 / 8.80 | 148 |

サブバンドは下端を含み上端を含まない区間とし、最後の2,000〜3,400 Hzだけ上端も含めます。48,000/8,192 Hz刻みで、ビン番号は順に52〜85、86〜170、171〜341、342〜580です。34＋85＋171＋239＝529ビンで、境界の重複はありません。[サブバンドCSV](analysis/wideband-subbands.csv)には全ビン番号、線形電力、低SNR数を保存しています。低域は34ビン中28ビンが低SNRで、予測の不確かさが大きい区間です。

交差予測でも片側比の増音が残り、反復1→2では77ビン、反復2→1では65ビンが負値です。約931.64 Hzではそれぞれ−5.16 dB、−4.61 dBでした。最大の増音は低SNRの約1,623.05 Hzで、−7.18 dB、−5.42 dBです。全帯域の総合低減を一様な改善とは扱えません。これらの周波数を除外したり、帯域を自動縮小したりしていません。

過去の500〜1,000 Hzの交差予測5.12〜5.53 dBと、今回の広帯域値は評価帯域・設計重み・等エネルギーを与えるビン集合が異なります。過去の約931.64 Hzの増音約2.5〜6.6 dBも含め、[狭帯域の予測CSV](analysis/experimental-fir-predictions.csv)を変更せず保持しています。

## 再実行と出力

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio1\jbr'
.\gradlew.bat :core:experimentalFir '-PexperimentMode=wideband' '-PexperimentOutput=../build/wideband-audit/offline' --console=plain
python tools/summarize_wideband.py build/wideband-audit/offline docs/analysis
```

Pythonはcoreが生成した結果を集計するだけで、別のFIR設計器を実装していません。入力がない場合は`index.json`に不足を記録します。現在の設置で新規測定を始めるために、保存データの解析成功を待つ必要はありません。
