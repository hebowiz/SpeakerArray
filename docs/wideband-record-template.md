## 比較実行の対応

| 実行 | 実行ID・日時 | 結果JSON・退避ファイル | 内部ラウンド数 | 完了／評価不能／中止／取消・理由 | 条件変更 |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 再試行 | | | | | |

数値は[比較集計CSVテンプレート](templates/wideband-comparison-template.csv)へ記入するか、`tools/summarize_comparisons.py`でJSONから取り出します。全帯域と各サブバンドについて、片側比・両側比・保守的下限・基準変動・候補ばらつき・ノイズ床・評価可能性を記録します。内部3ラウンドと、経路を開き直す3実行を混同しないでください。

CSVの`noiseFloorPower`はJSONに保存した線形電力です。画面のノイズ床はdB表示なので、その値を線形電力の欄へ転記せず、JSONの値か集計ツールの出力を使ってください。
